# matthewmoorejr.com

Matthew Moore Jr.'s personal site: a small 3D apartment you can walk around.

- `index.html` – page and UI
- `js/main.js` – the apartment, controls, and panels
- `js/games.js` – Lacrosse Range, Booster Landing, Market Parkour
- `js/leaderboard.js` – scores (add Supabase keys here for the global board)
- `vendor/` – three.js (MIT)
